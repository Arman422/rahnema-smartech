## اجرا

فایل `index.html` را در مرورگر باز کنید.

کلیدها: `←` / Space = بعدی · `→` = قبلی · `F` = تمامصفحه · `K` = نمایش/مخفی دکمه‌های footer

روی اسلایدهای محتوا، عنوان بخش در نوار پایین می‌ماند (روی جلد و divider خاموش است).
جمله باز اسلاید جدا ندارد — گفتاری با شروع بخش ۰۱؛ کاور فقط خوش‌آمد (`../rehearsal/00-cover-open.md` و `01-faza.md`).
دکمه‌های footer پیش‌فرض مخفی‌اند؛ برای rehearsal: `K` یا `?keys` در URL.

## برگشت مقیاس تایپ

اگر آزمایش hierarchy را نپسندیدید:

```bash
cp presentation/slides/index.before-type-scale.html presentation/slides/index.html
```
