# چک‌لیست rehearsal کامل

بعد از یک دور ۱۵ دقیقه‌ای، بدون نگاه به اسلاید جواب بده.

## شش سؤال تسلط

1. چه تصمیمی؟ → ورود مشروط به کمپین لوپ؛ نه کامل، نه عدم‌ورود  
2. برای چه کسی، چه مسئله‌ای؟ → صاحب بودجه؛ ۴–۵ ساعت دستی؛ بودجه با حدس (آی-۰۴)  
3. چه شواهدی دارید / ندارید؟ → آی-۰۱ و رفتار متوسط دارید؛ صاحب بودجه و شدت ندارید  
4. چرا خط است نه فیچر؟ → طرح+اجرا+نتیجه؛ مسیر جایگزین ادتریس اگر گیت رد شود  
5. سه عدد اقتصاد + Ask مرحلهای؟ → مثلاً ۲۰۹۰ / ۷۶٪ / ۴٫۳ (+ سقف ۸٫۹ یا SAM) و ۱۵۰→۲۰۷۰→۱۷۰۴۰  
6. چه چیزی توصیه را می‌کشد؟ → رد گیت‌ها (داده، خریدار، بازار، پیش‌بینی) یا شکست پایلوت  

## باید در ۱۵ دقیقه شنیده شود

- [ ] ورود مشروط + کیفیت تصمیم ≠ اندازه/اجرا  
- [ ] اسمارتک: هویت / مشتریان / چهار راهکار (بدون قاطی با ICP خط)  
- [ ] فضا: اندازه و اجرا → خلأ کیفیت تصمیم (برچسب تفسیر تیم)  
- [ ] ICP + ۲٫۱ همت  
- [ ] آی-۰۴ مسئله  
- [ ] صفر مصاحبه صاحب بودجه  
- [ ] آی-۰۱  
- [ ] حق ورود ≠ AI  
- [ ] سه فاز + دولایه  
- [ ] دمو ≤ ۳ دقیقه (یا صریح رد شد چون زمان)  
- [ ] چند عدد اقتصاد + ظرفیت نه رویای تقاضا  
- [ ] سرمایه مرحلهای + ماه ۱۹ / سال۲ منفی  
- [ ] گیت + پایلوت + توقف  
- [ ] آنچه نمی‌دانیم
