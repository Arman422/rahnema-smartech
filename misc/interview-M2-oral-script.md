# اسکریپت مصاحبهٔ شفاهی — محصول ۲ (شبیه‌سازی کمپین)

| فیلد | مقدار |
|---|---|
| هدف دور | آزمون فرضیه‌های H1–H5 (تقاضا/رفتار)؛ نه دموی محصول و نه دقت مدل |
| مخاطب | پرفورمنس مارکتر / مسئول کمپین / تحلیل‌گر (ترجیحاً آخرین کمپین UA) |
| مدت پیشنهادی | ۳۰–۴۰ دقیقه |
| منبع | `CONTEXT.md` (H1–H5) + P2 §۲.۵.۱ |
| پروتکل | رضایت شفاهی؛ ناشناس‌سازی؛ تفکیک مشاهده / گفته / تفسیر / فرضیه |
| تاریخ | ۲۰۲۶-۰۹-۰۸ |

**یادداشت مجری:** دربارهٔ گذشته بپرس («آخرین کمپین»)، نه علاقه به ایده. «جالب است» را به‌عنوان تقاضا ثبت نکن.
